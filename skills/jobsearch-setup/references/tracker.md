# Трекер в Google Таблицах

Один трекер на человека, в его Google Drive. Перед созданием загрузи скилл google-workspace (если он есть в сессии) и действуй по нему. Нет Google Drive — предложи подключить; если человек не хочет, сделай .xlsx (скилл xlsx) и скажи, что сводка тогда сможет обновлять его только при связи с компьютером.

## Лист «Отклики» (название на языке человека)

Строка 1 — заголовки, закреплена. Колонки в этом порядке — остальные скиллы рассчитывают на него:

| # | Колонка | Что писать | Проверка данных |
|---|---|---|---|
| A | Дата | дата добавления | дата |
| B | Компания | | |
| C | Роль | название как в вакансии | |
| D | Источник | портал / сайт компании / рекомендация / рассылка | список, см. ниже |
| E | Язык | язык документов | список языков человека |
| F | Статус | | список, см. ниже |
| G | Последний контакт | дата | дата |
| H | Следующий шаг | что сделать и до когда; «⚠️» в начале — нужно действие человека | |
| I | Оценка | 1–5 | 1,2,3,4,5 |
| J | Размер компании | <50 / 50–250 / 250–1000 / 1000+ / ? | список |
| K | Город | город или «удалённо» | |
| L | Заметки | условия, пробелы, контакт в компании | |
| M | Ссылка | на вакансию | |

**Статусы** (переведи на язык человека, смысл сохрани):
Подготовлено · Отправлено · Получение подтверждено · Скрининг · Собеседование · Финальный этап · Оффер · Отказ · Нет ответа · Отозвано

**Источники:** заполняются по рыночному пакету (порталы страны) + «Сайт компании», «Рекомендация», «Рассылка», «Другое».

## Лист «Сводка»

Формулы, без ручного ввода:
- число строк по каждому статусу (COUNTIF по колонке F);
- всего откликов;
- доля ответов: (всё, кроме «Подготовлено», «Отправлено», «Нет ответа») / «Отправлено и дальше»;
- приглашения на собеседование по источнику (COUNTIFS по D и F).

## Оформление

Спокойное: заголовки жирные с лёгкой заливкой, чередование строк, ширина колонок по содержимому, перенос текста в «Заметках» и «Следующем шаге». Условное форматирование статусов — мягкими цветами (оффер — зелёный, отказ — серый, нужно действие — жёлтый).

## После создания

- Ссылку — в `04_Processes`, раздел «Где что лежит».
- Если в первой встрече были вакансии, на которые человек подаётся, — добавить строками со статусом «Подготовлено».
- Показать человеку: ссылка + одна строка «колонки „Следующий шаг“ и „Статус“ — главное, остальное заполню я».
